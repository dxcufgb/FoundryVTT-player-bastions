The party's Bastion as a place on the map, built on top of the dnd5e system's own Bastion (2024 DMG). The GM founds it with a marker on a map and a few questions about the site; the Bastion page turns its stats into numbers you can feel: how many days it holds against a given assault, how long the food lasts, how often merchants come, how long a letter takes to get home.

The party plans, pays for and queues new buildings from a catalog of 69, building crews work through the queue, and every finished project shows on the Bastion's own battle map, walls, doors and lights included. Away from home, orders go out by envoy, letter, messenger bird or spell. Bastion events, merchants, sieges and a full history are included, and time passes with the game clock or with the party's long rests.

**Foundry VTT:** v13 · **System:** dnd5e 5.2.5+

## Installation

In Foundry: **Add-on Modules → Install Module**, paste this link into **Manifest URL** at the bottom, and click **Install**:

```
https://github.com/dxcufgb/FoundryVTT-player-bastions/releases/latest/download/module.json
```

Requirements and updating: see [Installation](https://github.com/dxcufgb/FoundryVTT-player-bastions/wiki/Installation) in the wiki.
